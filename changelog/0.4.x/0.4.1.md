# 0.4.1 — 2026-07-11

## Changed

- **Dockerfile** — build stage pins `oven/bun:1.3` → `1.3.14` (production stage too) and installs with `--ignore-scripts` (the build only runs `tsc`; `@duckdb/node-api` ships prebuilt platform binaries, not a postinstall).
- **`bunfig.toml`** — `minimumReleaseAge` supply-chain guard blocks package versions published less than 3 days ago; `@cyanheads/mcp-ts-core` is excluded so framework releases still adopt same-day.
- **`devcheck.ts`** outdated-dependency check now treats a `bun outdated` row held back solely by `minimumReleaseAge` (the `*` marker) as a non-finding instead of requiring an allowlist entry; `devcheck.config.json`'s `outdated.allowlist` emptied accordingly.
- **New:** `.github/SECURITY.md`, `.github/FUNDING.yml`, `.gitattributes` (LF normalization, binary/generated-file rules) — synced from the framework template.
- **`package.json`** `author` and **`LICENSE`** copyright normalized to `Casey Hand`.

## Fixed

- **`openfda_search_drug_approvals`** — `search` example corrected from `sponsor_name:"pfizer"` to `sponsor_name:"PFIZER"`; the field is stored uppercase and a lowercase quoted value returns zero matches. ([#20](https://github.com/cyanheads/openfda-mcp-server/issues/20))
- **`openfda_search_adverse_events`** — `sort` describe replaced a single drug-only example (`receivedate:desc`) with the sortable date field per category: drug → `receivedate` (or `receiptdate`), food → `date_created` (or `date_started`), device → `date_received` (or `date_of_event`). ([#23](https://github.com/cyanheads/openfda-mcp-server/issues/23))
- **Unmapped-sort 500 reclassification** — sorting or filtering on a field absent from an index's mapping (e.g. `receivedate:desc` on the food/device adverse-event indices, which lack that field) returns openFDA's `query_shard_exception` 500; previously fell through the generic 5xx branch and retried 4× on a query that can never succeed. Now matched alongside `token_mgr_error`/lexical-error/`illegal_argument_exception` and reclassified to a non-retryable `query_error`. ([#23](https://github.com/cyanheads/openfda-mcp-server/issues/23))
