# 0.4.2 — 2026-07-11

## Fixed

- **`formatRemainingFields`** (`format-utils.ts`) — dropped the 300-char default truncation cap on the catch-all "remaining fields" renderer shared by every search tool's `format()`, so `content[]` renders the same complete values as `structuredContent`. ([#21](https://github.com/cyanheads/openfda-mcp-server/issues/21))
- **`openfda_lookup_ndc`** — `packaging[]` previously capped at 5 entries (`... and N more`); now renders every entry.
- **`openfda_search_adverse_events`** — device `mdr_text[].text` narrative (previously truncated to 500 chars) and the JSON fallback record dump (previously sliced to 1000 chars) now render in full.
- **`openfda_search_device_clearances`** — `statement_or_summary` (previously capped at 500 chars) and the JSON fallback record dump (previously sliced to 500 chars) now render in full.
- **`openfda_search_drug_approvals`** — `submissions[]` previously capped at 10 entries (`... and N more`); now renders every entry.
- **`openfda_search_drug_shortages`** — `availability` (400-char cap) and `contact_info` (200-char cap) now render in full.
- **`openfda_search_recalls`** — `product_description` and `reason_for_recall` (previously capped at 300 chars each) now render in full.
