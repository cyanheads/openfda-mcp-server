# 0.4.0 — 2026-07-03

## Added

- **`openfda_describe_fields`** now covers `device/classification`, `device/registrationlisting`, `device/udi`, `device/covid19serology`, and `other/substance` — the 5 count-only endpoints previously exposed only by `openfda_count_values` — reaching 20-endpoint parity between the two tools. ([#16](https://github.com/cyanheads/openfda-mcp-server/issues/16))

## Fixed

- **`openfda_drug_profile`** — `label.warnings` falls back `boxed_warning ?? warnings_and_cautions ?? warnings`, so Rx labels carrying a boxed warning (e.g. metformin, Humira) surface their safety text instead of `null`. ([#19](https://github.com/cyanheads/openfda-mcp-server/issues/19))
