# 0.7.4 — 2026-08-25

## Added

- **`tests/mcp-server/tools/definitions/wire-contract.test.ts`** pins two wire guarantees across every tool definition: an unrecognized argument key is rejected by name with `additionalProperties: false` advertised to match, and no output field is named `error`.
- **`.github/CONTRIBUTING.md` and `.github/CODE_OF_CONDUCT.md`** — filing guidance, the server-vs-framework routing question, and the project's conduct baseline.

## Changed

- **`@cyanheads/mcp-ts-core` `^0.11.1` → `^0.12.3`** carries the framework's MCP SDK v2 migration. All 14 tools now advertise `additionalProperties: false` and JSON Schema 2020-12; an unrecognized argument key is rejected by name rather than stripped, so a caller's typo fails instead of silently returning a wrong answer.
- **`outputSchema` declares the failure envelope** — an `error` property, no top-level `required` list, and an `anyOf` carrying the success/failure branch split. Input-validation failures now read as a flat `path: message` sentence rather than a serialized issue blob.
- **The HTTP transport serves protocol revision `2026-07-28`** — `/.well-known/mcp.json` reports it as `mcp_version`, `initialize` advertises `resources.listChanged`, `resources.subscribe`, and `logging`, and a POST with a non-JSON `Content-Type` answers `415`.
- **`MCP_SESSION_MODE=stateless` is set in `.env.example`**, matching the `Dockerfile` — a source run and a container run no longer resolve different session modes.
- **`openfda-service.ts` passes the handler `Context` straight through to `fetchWithTimeout` and the retry wrapper**, so trace, span, session, and tenant ids join the upstream call's logs and metrics; only `operation` is overridden.
- **`Dockerfile` pins Bun 1.4.0**, mounts a BuildKit cache on each install, drops the framework's optional peer tiers with `--omit=peer`, and creates a `bun`-owned `data/openfda-mirror` for the opt-in bulk mirror.
- **`scripts/devcheck.ts`'s audit classifier accepts the Bun 1.4 `bun audit` format** — `pkg@versions` headers and ASCII `>` path separators — alongside the pre-1.4 spelling, under which every transitive advisory read as a direct hit and hard-failed the gate ([mcp-ts-core#390](https://github.com/cyanheads/mcp-ts-core/issues/390)).
- **Security reports route to `security@caseyjhand.com`** in `.github/SECURITY.md`.

## Synced

- 25 framework skills refreshed in `skills/`, with the `.claude/skills/` mirror regenerated; `changelog/template.md` picks up the framework's tightened authoring guide.
- `scripts/lint-mcp.ts` drops the removed `taskHandlers` branch and `scripts/lint-packaging.ts` checks `@modelcontextprotocol/server` in place of `@modelcontextprotocol/sdk`.
