# 0.7.9 — 2026-09-22

## Fixed

- **`openfda_get_drug_label`** renders `*_table` sections as GFM Markdown tables in `content[]` — entities decoded, `colspan`/`rowspan` expanded into a rectangular grid, captions and footnotes preserved — instead of raw SPL markup; `structuredContent` keeps the provider string unchanged ([#45](https://github.com/cyanheads/openfda-mcp-server/issues/45)).
- **`openfda_get_drug_label`** numbers table footnotes in one `[^n]` sequence across every table, section, and record in a response, so no footnote label is defined twice ([#61](https://github.com/cyanheads/openfda-mcp-server/issues/61)).
- **`openfda_search_recalls`** renders `device/recall` records with their own identity (`product_res_number`) and status (`recall_status`) fields instead of the enforcement header's `N/A`/`Unclassified` ([#46](https://github.com/cyanheads/openfda-mcp-server/issues/46)).
- **`openfda_search_recalls`** stages `device/recall` rows against a column projection matching the endpoint's own fields, instead of the enforcement schema that dropped identity and status from the staged table ([#59](https://github.com/cyanheads/openfda-mcp-server/issues/59)).
