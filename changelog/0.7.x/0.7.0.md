# 0.7.0 — 2026-07-27

## Added

- **Local bulk mirror** (`src/services/openfda/mirror/`) — an opt-in, self-refreshing SQLite copy of four openFDA bulk-download datasets: `drug/label`, `drug/ndc`, `drug/enforcement`, `drug/drugsfda`. Off by default (`OPENFDA_MIRROR_ENABLED=false`); `OpenFdaService.query` is the unmodified live path until it's set. ([#4](https://github.com/cyanheads/openfda-mcp-server/issues/4))
- **Mirror query gate** (`mirror/query.ts`) — answers a query locally only when it's a single quoted `field:"value"` term on a declared key, in canonical case, with no `count`/`sort`, `skip === 0`, and the whole match set fits the requested page; anything else routes live. `openfda_count_values` is never mirrored.
- **New env vars**: `OPENFDA_MIRROR_ENABLED`, `OPENFDA_MIRROR_PATH` (default `./data/openfda-mirror`), `OPENFDA_MIRROR_REFRESH_CRON`, `OPENFDA_MIRROR_FALLBACK_LIVE` (default `true`), `OPENFDA_MIRROR_REFRESH_TIMEOUT_MS` (default `21600000`), `OPENFDA_MIRROR_BASE_URL`.
- **`scripts/openfda-mirror.ts`** backing `bun run mirror:init | refresh | verify | status`. Init runs out-of-band and is never triggered by server startup; refresh re-reads whole dump partitions (openFDA publishes no incremental API for these endpoints) and tombstones rows the new export no longer carries.
- **GMDN licensing carve-out** — `MIRRORED_ENDPOINTS` is a closed list of four drug datasets, and `assertNoGmdnContent` walks every ingested record for a GMDN-bearing key before it reaches the store, aborting the sync if one is found. GMDN® Term Code/Name/Definition are licensed from The GMDN Agency and excluded from this mirror.
- **`scheduleMirrorRefresh()`**, wired into `setup()` — registers the refresh cron via `schedulerService` when the mirror is enabled, a cron is set, and the transport is HTTP; stdio operators run `mirror:refresh` from the host instead.
- Optional peer dependencies `better-sqlite3` (`>=11`, Node only — Bun uses built-in `bun:sqlite`) and `node-cron` (`>=4`, only needed for `OPENFDA_MIRROR_REFRESH_CRON`).
- README **Local bulk mirror** and **Data attribution** sections — mirror scope/config, and the openFDA CC0 license with the GMDN exception.

## Changed

- **`OpenFdaService`'s constructor now takes `OpenFdaServiceConfig`**, a narrower type than the full `ServerConfig` — `apiKey`/`baseUrl` required, `mirrorEnabled`/`mirrorFallbackLive` optional — so a live-only client can be built from just the API config.
- **`setup()` in `src/index.ts` is now async**, awaiting `scheduleMirrorRefresh(core.config.mcpTransportType)` after service init.

## Fixed

- **`scripts/tree.ts` never matched directory-only gitignore patterns.** `isIgnored()` tested every entry with a plain relative path, so a pattern written with a trailing slash (`/data/`, `.claude/`) — which `ignore` matches only against directories — never hit, and gitignored directories leaked into the generated `docs/tree.md`. Directory entries are now tested with a trailing slash appended. Filed upstream as [cyanheads/mcp-ts-core#304](https://github.com/cyanheads/mcp-ts-core/issues/304), since the generator originates in the framework template.
