# 0.7.7 — 2026-09-22

## Changed

- **Canvas staging surfaces** — the staging notice, `content[]` line, `stage` input description, `canvas_table` and `spilled` output descriptions, and each staging tool's `description` now name `openfda_dataframe_describe` before `openfda_dataframe_query`, since the inline preview renders nested fields (`openfda.brand_name`, `products[].marketing_status`) that aren't real canvas columns ([#50](https://github.com/cyanheads/openfda-mcp-server/issues/50)).
- `tests/` now typechecks under `bun run devcheck`; `tsconfig.build.json` still drives `bun run rebuild` and emits only `src/`. The `stagingNotice` test fixture that had drifted from `OpenFdaSpillResult` (missing `previewBudget`) is fixed at the fixture ([#51](https://github.com/cyanheads/openfda-mcp-server/issues/51)).

## Fixed

- **`openfda_search_adverse_events`, `_animal_events`, `_device_clearances`, `_drug_approvals`, `_drug_shortages`, `_recalls`, `_tobacco_reports`, and `openfda_lookup_ndc`** now declare `canvas_not_found` and `canvas_capacity_exhausted` in `errors[]` — both already reachable from the framework's `canvas.acquire()`, previously undeclared ([#54](https://github.com/cyanheads/openfda-mcp-server/issues/54)).
