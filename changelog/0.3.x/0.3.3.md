# 0.3.3 — 2026-07-03

Security and reliability patch — three bug fixes plus a bundled dependency refresh that clears 8 upstream security advisories.

## Changed

- **`openfda-service.ts`** now issues requests through the framework's `fetchWithTimeout` — Bun-safe timeout handling, `http.client.request.duration` telemetry, and api_key-redacted URLs in logs/errors.
- **`@cyanheads/mcp-ts-core`** `^0.10.9 → ^0.10.10`.
- **`@biomejs/biome`** `^2.5.0 → ^2.5.2`.
- **`@types/node`** `^26.0.0 → ^26.1.0`.

## Fixed

- **5xx query-error reclassification** — a malformed search or a `count`/aggregation on a non-keyword field returns HTTP 5xx from openFDA and was retried 4× as a transient `upstream_error`; now reclassified to a non-retryable `query_error` when the body carries a `token_mgr_error`, lexical-error, or `illegal_argument_exception` marker. Marker-free 5xx responses stay retryable. Covers every search tool and `openfda_count_values` via the shared classifier. ([#14](https://github.com/cyanheads/openfda-mcp-server/issues/14))
- **`openfda_dataframe_describe` / `openfda_dataframe_query`** — the disabled-DataCanvas path now throws a typed `canvas_disabled` validation error (was an untyped `InternalError`/-32603). ([#15](https://github.com/cyanheads/openfda-mcp-server/issues/15))
- **Canvas spillover inline preview** — `limit`/`skip` now bound the inline preview window on all 8 search tools plus `openfda_lookup_ndc` (was a byte-budgeted count that silently rewrote `meta.limit`); the full matched set still stages to the canvas regardless of the inline cap. ([#18](https://github.com/cyanheads/openfda-mcp-server/issues/18))

## Security

- **`hono`** (via `@cyanheads/mcp-ts-core`) `4.12.26 → 4.12.27` — clears a CORS-credentials-with-wildcard-origin issue (high) plus four moderate issues: `serve-static` path traversal on Windows via encoded backslash, AWS Lambda `Set-Cookie` merge dropping cookies, Body-Limit bypass on Lambda via understated `Content-Length`, and a Lambda@Edge repeated-header drop.
- **`js-yaml`** (transitive) `3.14.2 → 3.15.0` — clears a quadratic-complexity DoS in merge-key handling via repeated aliases (moderate).
- **`vite`** (transitive, via `vitest` › `@vitest/mocker`) `8.0.14 → 8.1.3` — clears a `server.fs.deny` bypass on Windows alternate paths (high) and a bundled `launch-editor` NTLMv2 hash disclosure via UNC path handling on Windows (moderate).

`bun audit`: 8 advisories (2 high, 6 moderate) → 0.
