# 0.11.1 — 2026-11-25

## Added

- **Staged searches drain by `search_after` past the 25,000-row `skip` ceiling** ([#110](https://github.com/cyanheads/openfda-mcp-server/issues/110)). A broad match on `food/event`, `cosmetic/event`, `drug/orangebook`, or `other/nsde` stages more than 25,000 rows; drain pages share one 50 s deadline. A continuation that fails through the service's retries, or a link carrying a sort key's missing-value marker (an empty keyword value counts only when the page's last record lacks the field), goes on by `skip` up to 25,000 rows, and a failing `skip` page still fails the call.
- **`truncated_by`** on the eight staging tools' output (`size_budget`, `row_ceiling`, `time_budget`, `upstream_end`), present exactly when `truncated` is, and named in the staging notice and `content[]` line ([#110](https://github.com/cyanheads/openfda-mcp-server/issues/110)).

## Changed

- **The eight search tools build their enrichment through one function**, `enrichSearchPage` in `src/mcp-server/tools/search-enrichment.ts` ([#115](https://github.com/cyanheads/openfda-mcp-server/issues/115)). `openfda_lookup_ndc`'s `content[]` query line reads `Query: …` where it read `**effectiveQuery:** …`.
- **Cross-tool test suites check their hand-written tables against the tool registry** (`tests/helpers/tool-registry.ts`), and gain the rows for the endpoints they missed ([#116](https://github.com/cyanheads/openfda-mcp-server/issues/116)).

## Fixed

- **A sort openFDA refuses fails as `not_sortable`**, not `query_error` ([#113](https://github.com/cyanheads/openfda-mcp-server/issues/113)). The message names the endpoint, the field, and the form to try, and covers all three refusal shapes and sort keys of any length; the nine tools that take `sort` declare it.
- **A 200 whose body is not openFDA JSON fails as `upstream_error`** with `status: 200` and is retried like a 5xx, where it failed as a caller error with no reason ([#112](https://github.com/cyanheads/openfda-mcp-server/issues/112)).
- **`next_cursor` is withheld on a page whose next link carries a sort key's missing-value marker or repeats the page it was read from.** 0.11.0 handed out a cursor there that failed on a date sort or looped on a keyword sort, serving records already read. The page's notice names the way on (`skip` from its position within 25,000, an `_exists_:` clause per sort field, or another sort), and past the ceiling the page-size notice states the ceiling and leaves the way on to that notice.
- **`openfda_get_drug_label`'s `content[]` query line reads `Query: …`** where it read `**effectiveQuery:** …`.
- **`openfda_lookup_ndc`'s `sort` example is `marketing_start_date:desc`**, which both datasets accept; `listing_expiration_date` does not exist on `nsde`.
- **The GMDN licensing carve-out names `device/udi`** in `docs/design.md`, the README, and the `datasets.ts` comment; `device/classification` records carry no GMDN terms ([#111](https://github.com/cyanheads/openfda-mcp-server/issues/111)).
