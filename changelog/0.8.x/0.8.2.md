# 0.8.2 — 2026-10-25

## Changed

- **DataCanvas** defaults to DuckDB for npm and Docker; set `CANVAS_PROVIDER_TYPE=none` to disable staging and SQL. Explicit deployment and `.env` settings take precedence over the default.
- **MCPB bundle** explicitly disables DataCanvas because platform-specific DuckDB bindings are excluded; development sources, tests, and caches are omitted from the bundle.
- **Development tooling** syncs framework guidance and classifies a shared direct/transitive advisory against the version installed at the project root.
